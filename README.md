# تطبيق متابعة التفقد الميداني (Suivi Inspection)

منظومة متكاملة لمتابعة عمليات التفقد الميداني والزيارات البيداغوجية لمفتشي التربية، تهدف إلى توثيق أداء الأساتذة، تسجيل التقييمات التفصيلية، إرفاق المستندات، توليد تقارير PDF معتمدة، وتوقيعها رقميًا.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

### الخلفية (Backend)
- **Java 21 (OpenJDK)**
- **Spring Boot 3.2.5**
  - Spring Web
  - Spring Data JPA
  - Hibernate
  - Validation API
  - Spring Security (BCrypt)
- **PostgreSQL 16** (قاعدة البيانات الأساسية)
- **OpenPDF / iText** (لتوليد التقارير البيداغوجية بصيغة PDF)

### الواجهة الأمامية (Frontend)
- **React (Vite)**
- **Tailwind CSS v4** (دعم كامل وتنسيق متطور للغة العربية RTL)
- **Lucide React** (أيقونات تفاعلية)
- **HTML5 Canvas** (لتوقيع المتفقدين رقمياً بالماوس أو اللمس)
- **Playwright** (للاختبارات الآلية E2E وتأكيد الواجهات)

---

## ⚙️ المتطلبات الأساسية للتشغيل (Prerequisites)

قبل البدء بالتشغيل، تأكد من تثبيت الأدوات التالية على جهازك:
1. **Java SDK 21** (أو أحدث)
2. **Apache Maven 3.9+**
3. **Node.js v18+** و **npm**
4. **PostgreSQL 16**

## 🚀 خطوات التشغيل والتهيئة المحلية (Local Setup Guide)

### 1. تهيئة قاعدة البيانات (PostgreSQL)

قم بإنشاء قاعدة بيانات باسم `inspection` على خادم PostgreSQL المحلي الخاص بك:

```sql
CREATE DATABASE inspection;
```

تأكد من مطابقة بيانات الاتصال بقاعدة البيانات في ملف الإعدادات الخاص بالخلفية:
`backend/src/main/resources/application.properties`

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/inspection
spring.datasource.username=postgres
spring.datasource.password=admin
```

---

### 2. تشغيل تطبيق الخلفية (Spring Boot Backend)

انتقل إلى مجلد الخلفية وقم بتشغيل خادم التطبيق باستخدام Maven:

```bash
cd backend
mvn spring-boot:run
```

- سيبدأ الخادم على المنفذ المحلى: `http://localhost:8080`
- عند التشغيل الأول، سيقوم التطبيق تلقائيًا بإنشاء الجداول وحقن بيانات افتراضية بيداغوجية (Seeding) للتجريب السريع.

---

### 3. تشغيل تطبيق الواجهة الأمامية (React Frontend)

انتقل إلى مجلد الواجهة، وقم بتثبيت الحزم المطلوبة، ثم ابدأ خادم التطوير:

```bash
cd frontend
npm install
npm run dev
```

- سيبدأ تطبيق الويب على الرابط: `http://localhost:5173`
- تم إعداد ميزة الـ Proxy في ملف إعدادات Vite لتوجيه طلبات الـ API تلقائيًا إلى المنفذ `8080`.

## 🔐 بيانات الدخول التجريبية (Demo Accounts)

لقد قمنا بتهيئة حسابات تجريبية مشفرة بـ BCrypt داخل قاعدة البيانات تلقائيًا لتسهيل عملية المراجعة والتطوير:

| اسم المستخدم (Username) | كلمة المرور (Password) | الصلاحية / الدور (Role) |
| :--- | :--- | :--- |
| `admin` | `admin` | مدير النظام / مشرف عام |
| `inspecteur1` | `password` | متفقد ميداني |
| `inspecteur2` | `password` | متفقدة ميدانية |

## 🧪 تشغيل اختبارات النظام والتحقق

### اختبارات الـ Backend (JUnit)
لتشغيل اختبارات التكامل والتحقق من صحة واجهات الـ REST APIs:
```bash
cd backend
mvn test
```

### اختبارات الـ Frontend & E2E (Playwright)
لتشغيل سيناريو المحاكاة الآلي الكامل لتسجيل الدخول، إنشاء تفتيش جديد، وإصدار التقارير:
```bash
cd frontend
npx playwright test
```

## 📋 مميزات التطبيق الرئيسية

1. **دعم كامل للغة العربية (RTL):** واجهة مستخدم متكاملة ومصممة خصيصاً للمتحدثين بالعربية.
2. **لوحة تحكم ذكية (Dashboard):** تعرض إحصائيات فورية وذكية لعدد عمليات التفقد الجارية، المغلقة، والمفتوحة مع تصفية سريعة.
3. **توقيع رقمي تفاعلي:** نظام رسم توقيع مباشر باللمس أو الماوس وحفظه بشكل آمن لعرضه في التقرير النهائي.
4. **رفع المرفقات (Pieces Jointes):** رفع ملفات PDF وصور بسعة أقصاها 5 ميجابايت مع فحص أمان دقيق للملفات.
5. **توليد التقارير:** تصدير التقرير البيداغوجي بصيغة PDF قابلة للطباعة بكافة تفاصيل وعناصر التقييم.
